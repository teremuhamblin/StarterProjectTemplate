### 📄 Starter Project Template

A clean, professional, and reusable GitHub project template.  
Includes CI workflow, issue templates, PR template, tests, and a minimal Python example.

Features
- GitHub Actions CI (lint + tests)
- Issue templates (bug report, feature request)
- Pull Request template
- Python example project
- MIT License
- Ready for cloning and reuse

Getting Started

Run the project
```bash
python3 src/main.py
```

Run tests
```bash
pytest tests/
```

CI/CD
This project includes a GitHub Actions workflow that runs automatically on:
- push
- pull_request
